## Quick reference

- Dev: `npm run dev` · Build: `npm run build` · Typecheck: `npm run typecheck`
- **Before committing a visual change, update `README.md` and `docs/index.html`.**
  A `pre-commit` hook (`.claude/hooks/pre-commit`) enforces this.
