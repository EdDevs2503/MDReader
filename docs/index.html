The things that matter when you actually live in your Markdown and diagrams.

🔍 Navigate huge diagrams

Standalone .mmd files open in a pan & zoom viewport. Zoom resizes the SVG itself — so text stays razor-sharp at any level, not a blurry bitmap.

  • Scroll to zoom toward the cursor, drag to pan
  • Fit-to-screen, 100% reset and fullscreen
  • Inline mermaid blocks get an Expand button
flowchart.mmd

🪟 Arrange your workspace

Drag a tab to reorder it, move it to another pane, or drop it on a pane's edge to split the layout — a live highlight shows exactly where it lands. Open as many OS windows as you like.

  • VS Code-style drag & drop between panes
  • Drop on a side to create a split
  • Independent multi-window support

✍️ Edit, preview & rewind

A CodeMirror 6 editor with Preview / Split / Editor modes and a live preview. Every save snapshots the file, so you can diff any version against the present and restore it.

  • Live preview with a save-status footer
  • Per-file timestamped history
  • Diff & restore any previous version

## Usage
Everything else

Built for working with docs & diagrams

Nine features, one focused window.

📁

Add folders

Recursively scan directories for .md / .mmd and browse them in a filterable tree.

🧜

Full Mermaid

Standalone .mmd files and inline ```mermaid blocks, powered by Mermaid v11.

🔗

Linked files

Click a relative link to another document and it opens instantly in the active pane.

🖥️

Open console

Launch your terminal in a file's folder, or reveal it in the file manager, in one click.

➕

New files

Create a new .md / .mmd from a template with Ctrl/Cmd+N.

⌨️

Keyboard-first

Shortcuts for new file, save, split, history, sidebar and window management.

Under the hood

A modern, lightweight desktop stack

Electron Vite React 18 TypeScript CodeMirror 6 Mermaid 11 react-markdown Zustand
Run it locally

Up and running in three commands

Requires Node.js 18+.

# clone & install git clone https://github.com/EdDevs2503/MDReader.git cd MDReader && npm install # launch with hot reload npm run dev # package an installer (AppImage / dmg / nsis) npm run dist
