Welcome to MDReader

architecture.mmd

Everything in one window

Built for working with Markdown docs and Mermaid diagrams side by side.

📁

Add folders

Recursively scan directories for .md / .mmd files and browse them in a filterable tree.

🧜

Full Mermaid

Standalone .mmd files and inline ```mermaid blocks render with Mermaid v11.

🔍

Pan & zoom

Navigate huge diagrams: zoom toward the cursor, drag to pan, fit, 100% and fullscreen — text stays crisp.

🔗

Linked files

Click a relative link to another document and it opens instantly in the active pane.

🪟

Split & windows

Drag tabs to reorder, move between panes, or drop on an edge to split — plus independent OS windows.

🖥️

Open console

Launch your terminal in a file's folder, or reveal it in the file manager, in one click.

🕑

Change history

Every save snapshots the file. Diff any version against the current content and restore it.

✍️

Live editor

A CodeMirror 6 editor with Preview / Split / Editor modes and a save-status footer.

➕

New files

Create a new .md / .mmd from a template with Ctrl/Cmd+N.

Built with

A modern, lightweight desktop stack.

Electron Vite React 18 TypeScript CodeMirror 6 Mermaid 11 react-markdown Zustand

Get started

Clone, install and run in development mode.

# clone & enter git clone https://github.com/EdDevs2503/MDReader.git cd MDReader # install dependencies npm install # launch the app (hot reload) npm run dev # build & package an installer npm run dist # AppImage / dmg / nsis
